# BINGO! — みんなであそぶビンゴ

会場のモニターに映して使う、1〜75のビンゴ抽選サイト。React + Vite / Cloudflare Pages。

- ボタンまたはスペースキーで抽選（重複なし）
- 大きな番号表示、抽選アニメーション、効果音の切り替え
- 全画面表示、直近10件の履歴、全75番号の一覧
- ブラウザ内に進行状況を保存し、再読み込み後も復元
- リセットは確認画面付き。参加者は手元のビンゴカードを使用
- 各ブラウザで独立して進行。端末間のリアルタイム同期はありません

## 開発・検証

```sh
npm ci
npm run dev
npm test
npm run build
```

## 公開

```sh
npm run deploy
```

Cloudflareで認証済みのWranglerを使用。`dist/client`をPagesへ直接デプロイします。
Sites用のビルド成果物とWorkerも維持しています。

## デザイン

今回提供された参考画像のクリーム、コーラル、黄、ターコイズ、オレンジ、ラベンダーから新規に構成。既存プロジェクトのデザイン・画像は使用していません。
